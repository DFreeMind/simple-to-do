# 易简清单 0.4.7

## 主要更新

- 重做任务推进路径：今日视图区分今日计划、今天到期和建议加入；收集箱可直接加入今日、安排到明天或继续整理。
- 计划视图支持按周浏览和前后切换，逾期及周外任务仍保留在同一页面；已完成支持跨清单、时间范围和关键词回顾。
- 任务与专注形成双向入口：可从任务直接开始专注，已有专注投入可在任务详情查看并进入完整回顾。
- 新增并完善节律桌面控制器：默认停靠右上角，紧凑态显示当前节律，展开后处理多项提醒，支持再次收起并按实际项数调整高度。
- 优化任务完成状态、详情主题卡片和关联信息的展示层级，已完成任务保持清晰可读。

## 数据与兼容性

- 本版本继续使用本地 SQLite 数据；升级不会要求账号或云同步。
- 安装或大批量整理前，建议在“个人空间 → 数据与安全”创建本机恢复点。
