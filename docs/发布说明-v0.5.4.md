# 易简清单 0.5.4

## 主要更新

- 专注计时支持显示本次暂停时长，桌面控制器也会同步呈现暂停状态；提前结束的专注会保留未完成标记，同时将已投入的整分钟计入今日花圃成长。
- 专注花圃升级为更清晰的月度日格、目标达成和当日专注摘要；花种图鉴更新了舞台、阶段素材、成长回放与徽章展示。
- 自动更新无法安装时，可直接下载完整安装包到系统下载目录并定位文件，方便手动完成更新。
- 移除未使用的花种历史原图并收紧资源加载范围，显著缩小桌面安装包和更新下载体积。

## 数据与兼容性

- 继续使用本地 SQLite 数据；既有任务、专注记录、花园和成长徽章数据保持兼容，无需迁移。
- 建议在“个人空间 → 数据与安全”创建本机恢复点后再安装更新。
