# 易简清单 0.5.1

## 主要更新

- 专注成就升级为成长总览、花田回顾、花种图鉴和成长徽章四个清晰入口；年度花田可按月浏览，年度档案与近期足迹提供集中回顾。
- 当天花详情补充有效专注总时长、目标完成情况和按任务归类的起止时间线，让一天的投入更易回看。
- 花种图鉴与花圃新增解锁门槛、剩余分钟和进度信息；后期花种拉开解锁梯度，收藏过程更有阶段感。
- 继续优化今日、收集箱、计划、完成记录、任务详情、个人空间、主题和节律桌面控制器的布局与交互稳定性。
- “关于与更新”中的更新源选择框不再遮挡文字；远端 Release Notes 会按标题、段落和列表清晰显示，长内容可滚动阅读。

## 数据与兼容性

- 继续使用本地 SQLite 数据；升级不会要求账号或云同步。
- 既有花园保持原有解锁状态，新梯度仅影响后续可解锁花种。
- 建议在“个人空间 → 数据与安全”创建本机恢复点后再安装更新。
