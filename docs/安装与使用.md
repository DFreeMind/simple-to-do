# 安装与使用

## 易简清单适合谁

易简清单是一个本地优先的个人桌面待办应用，适合把一件复杂事情拆成下一步、在“收集—安排—完成”之间持续推进的人。它提供清单、子任务、计划、提醒、富文本备注和本机恢复点；不要求注册账号，也不提供云同步或多人协作。

## 下载与安装

从 [GitHub Releases](https://github.com/DFreeMind/simple-to-do/releases/latest) 下载最新安装包。请以 Release 页面实际展示的资产为准：

- Windows：下载 `simple-to-do_<version>_x64-setup.exe`，双击安装。升级前如应用正在运行，请先退出应用，避免安装器无法替换文件。
- macOS Intel：下载 `simple-to-do_<version>_x64.dmg`，打开后将“易简清单”拖入“应用程序”文件夹。首次打开如被系统拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
- macOS Apple Silicon：下载 `simple-to-do_<version>_aarch64.dmg`，安装方式与 Intel Mac 相同。

当前公开 Release 已提供 Windows x64、macOS Intel 与 macOS Apple Silicon 包；其他架构是否可用以 Release 资产为准。

## 检查与安装更新

应用启动后会静默检查更新。发现新版本时，侧栏的设置入口会显示提示；也可随时打开“设置 → 关于与更新”查看当前版本、本次更新亮点与历史说明。

1. 点击“检查更新”手动确认是否有新版本；开发环境不会请求在线更新服务。
2. 发现更新后，阅读更新说明并点击“下载并安装”。下载期间请保持应用打开。
3. 更新包下载后会自动校验签名。显示“更新已安装”时，点击“立即重新启动”即可使用新版本；若无法自动重启，退出应用后重新打开即可。
4. 可以跳过某个版本，后续发布更高版本时会再次提醒。更新源可选自动（自建服务器优先）、自建服务器或 GitHub；网络问题不会影响本机任务数据。

更新不会主动上传任务内容。进行大批量整理前，建议先在“个人空间 → 备份与恢复”创建本机恢复点。

## 第一次使用

1. 在**收集箱**记录临时想法，或在**今日**直接添加马上要做的事。收集箱顶部会提示“待决定项”，可逐项直接加入今日、安排到明天，或打开详情继续整理。
2. 给任务补充清单、截止日期、提醒、优先级和标签；复杂事项继续拆成子任务。
3. 在**计划**中按周查看已安排任务；可前后切换周，逾期和周外任务不会被隐藏，按天承接已安排任务。不再合适的任务可重新安排到今天或明天。
4. 在任务详情中写备注、插入图片，或将任务放入清单内的任务分组；也可直接开始专注，之后在详情里回看关联投入。
5. 完成后的任务集中在侧栏顶部的**完成记录**：可跨清单按完成时间、清单、近 7 天 / 30 天 / 全部或关键词回顾，仍可打开详情或恢复为未完成。删除则先进入垃圾桶。
6. 进行大批量整理前，可在“个人空间 → 备份与恢复”创建恢复点。

## 常用快捷键

| 操作 | Windows | macOS |
| --- | --- | --- |
| 打开搜索 | `Ctrl + K` | `⌘ + K` |
| 快速添加任务 | `N` | `N` |
| 将选中任务加入今日 | `D` | `D` |
| 关闭当前弹层 | `Esc` | `Esc` |
| 富文本加粗 / 斜体 | `Ctrl + B` / `Ctrl + I` | `⌘ + B` / `⌘ + I` |

快捷键只在应用窗口处于前台时生效。输入框、富文本编辑器和打开的弹层会优先接收按键，避免误操作。

## 数据、隐私与恢复

- 任务、设置和本机个人资料保存在应用数据目录内的 SQLite 数据库；图片附件以独立文件保存，数据库不保存图片 base64。
- 应用不要求账号，不上传任务内容，也不提供云同步。系统提醒需要操作系统授予通知权限。
- 可以在“个人空间 → 存储与清理”扫描未引用附件，将其移入清理站、恢复或永久删除。
- 可以在“个人空间 → 备份与恢复”创建、打开、恢复或删除本机恢复点。恢复前应用会先创建安全点；恢复点包含数据库、附件和头像。

如需迁移或重装，先创建恢复点，再妥善保存该恢复点目录。不要直接编辑 SQLite 数据库或附件目录。

## 已知边界

- 不支持账号登录、云同步、共享清单、协作、外部日历同步、番茄钟、习惯和四象限。
- 普通文件附件尚未开放；当前支持图片附件。
- 自动更新仅在对应 Release 提供已签名更新清单时可用；没有清单时，应用会提示前往 Release 手动下载安装包。
- 应用启动后会静默检查一次更新，发现新版本在「设置 → 关于与更新」显示角标；可跳过指定版本，新版本发布后会再次提示。
- Windows 与 macOS 均在对应架构的 Release 提供已签名更新包时支持应用内更新。macOS 安装包尚未经过 Apple notarization；首次手动打开如被系统拦截，请在系统设置中确认后继续。
- 节律提醒运行时可打开桌面控制器：默认位于屏幕右上角，紧凑态展示当前节律；展开后可处理至多三项提醒，并可再次收起。关闭控制器不会暂停节律。

请在 [GitHub Issues](https://github.com/DFreeMind/simple-to-do/issues) 中说明：系统版本、应用版本、发生步骤、预期结果和实际结果。请勿附带真实任务内容、数据库或其他隐私文件；可使用脱敏截图复现问题。
