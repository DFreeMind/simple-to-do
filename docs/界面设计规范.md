# 界面设计规范

## 布局
- 桌面端采用三栏结构：左侧导航、中央任务列表、右侧任务详情。
- 左侧导航宽度约 286px，可折叠为 56px 图标栏（Rail）。
- 展开态侧栏顶部使用“个人空间入口”替代纯应用图标卡：左侧为 40px 圆角头像，右侧为昵称与“个人空间 · 本地数据”副标题；首个未设置头像时显示由昵称生成的默认头像。应用名称保留在窗口标题或该入口的次级信息中，不与用户昵称竞争主视觉。
- 点击个人空间入口打开右侧个人资料抽屉，可修改昵称、更换头像或恢复默认头像；不改变当前任务视图，也不将点击行为绑定到“今日”。完整的资料卡本身应通过 hover、焦点和按钮语义表达可点击性，不添加仅用于提示点击的箭头。抽屉顶部身份卡即为编辑区：点击头像更换头像，直接在名称位置编辑昵称；昵称在失焦、按 Enter 或停止输入后自动保存，头像操作立即生效，因此不提供“取消 / 保存”按钮。抽屉使用当前主题的低饱和身份卡、焦点和状态色，但主体保持中性表面。入口右侧仅在已具备相应能力后展示同步状态或空间切换箭头，未实现时不可展示登录、协作等暗示性操作。
- 个人空间抽屉采用与应用设置一致的“左侧分类 + 右侧内容”布局，固定信息架构为：概览、存储与清理、备份与恢复。概览整合昵称、头像、仅本机保存状态、最近恢复保护和空间检查入口，不重复主任务视图中的任务数量。账号、同步和协作未进入当前范围时不展示占位入口。
- Rail 折叠态顶部显示头像按钮，悬停/键盘聚焦时展示昵称和“个人资料”提示；点击仍打开个人资料抽屉。
- 折叠态 Rail 顶部固定显示搜索图标，随后以分隔线区分主要视图图标（今日/收集箱/计划/重要）、清单入口（点击弹出浮动卡片）、维护视图图标（已完成/垃圾桶）、设置和展开按钮；当前视图用左侧彩色竖线标识。
- 搜索入口使用现有搜索视图和查询范围；点击 Rail 图标或按 `Ctrl/Cmd + K` 后聚焦搜索输入框，设置等模态层打开时不响应快捷键。
- 搜索视图支持列表和分组两种模式：列表模式连续展示结果；分组模式按所属清单归类，组头显示清单颜色、名称和结果数并支持折叠。搜索仅匹配标题、标签、重复规则及富文本备注的可见纯文本；结果展示任务分组与命中位置，并高亮标题和标签中的关键词。
- 清单浮动卡片：从图标右侧弹出的紧凑卡片（232px 宽，最大 400px 高），包含搜索框、分组清单列表和新建按钮，支持滑入动画。
- 中央列表为主工作区，包含视图标题、快速添加、今日建议、任务列表和空状态。
- 右侧详情默认宽度约 380px，显示任务属性、子任务、富文本备注和低频操作；支持在 320–800px 间拖拽调整并持久化。
- 窗口较窄时详情面板覆盖在右侧。产品交付目标是桌面端；窄窗口适配用于保障桌面小尺寸可用，不将其宣传为移动端产品。

## 视觉
- 使用 token 化主题，当前支持青绿、海蓝、紫罗兰、石墨四套配色。
- 背景以浅灰白为主，强调色只用于选中、焦点、重要动作和状态反馈。
- 多分组任务视图使用中性任务画布；分组颜色只作为标题左侧色条、图标、计数和轻微悬停底色的识别锚点，不使用整块彩色背景或任务行彩色边框。
- 控件圆角以 6px、8px、12px、16px 分层，避免大面积圆润卡片化。
- 结构性图标使用 `lucide-vue-next` 线性图标，不使用 emoji 作为导航或系统图标。
- 所有可点击控件必须有 hover、focus-visible、disabled 或 active 状态。

## 瞬时浮层与下拉菜单
- 下拉菜单、筛选面板、日期选择器、更多菜单等瞬时浮层默认不改变页面布局，使用浮层展示并与触发控件保持明确的锚定关系。
- 任何瞬时浮层都必须支持：点击其交互范围外关闭、按 `Esc` 关闭、选择完成后关闭（多选/编辑型浮层可由明确的“完成”操作关闭）。同层互斥的菜单打开时，其他同层菜单应关闭。
- 外部点击检测统一使用 `pointerdown` 的捕获阶段监听，不能依赖冒泡阶段的 `click`，以免内部 `stopPropagation` 导致浮层残留。
- 使用 Teleport 渲染的子菜单必须被视为父浮层的交互范围；点击子菜单不应误关父浮层，点击其他区域则应同时关闭相关瞬时浮层。
- 浮层打开时保持可见焦点状态；关闭后不改变页面内容，不抢占键盘焦点。按钮必须同步维护 `aria-expanded`，菜单使用相应的 `menu` / `listbox` 语义。

## 任务列表
- 每行包含完成框、标题、清单、日期、今日、重复、子任务、附件、标签等元信息。
- 鼠标悬停或键盘聚焦时显示行内操作：加入今日、重要、更多。
- 已完成任务默认可折叠，设置中可切换。
- 计划视图按日期分组，不在该视图直接添加任务。
- 今日视图显示建议加入今日的任务，点击建议即加入今日。

## 任务详情
- 顶部使用任务核心卡片：第一行放完成状态和快捷图标操作，包含加入今日、重要、置顶和关闭详情。
- 标题在概览卡中独占一行编辑；短标题保持一行紧凑，长标题最多两行，超出后在标题框内滚动。
- 概览卡只保留任务标题和轻量子任务进度，不重复展示清单、日期、提醒等属性信息。
- 顶部快捷图标使用低对比按钮组承载，避免图标散落；激活状态用青绿色强调，关闭操作保持弱化。
- 属性区使用轻量面板承载清单、截止日期、提醒、重复、优先级和标签；属性值区域必须支持长文本，长清单名最多两行显示且不得挤压下拉箭头。
- 子任务与富文本备注同时存在，不再使用详情/检查事项模式切换。
- 空白备注默认显示紧凑“添加备注”入口，聚焦后展开；工具栏以图标式块类型菜单代替原生下拉，并提供放大按钮进入独立编辑器。`/` 命令在光标旁以高层浮层提供标题、列表、待办、引用、分割线和图片插入，须始终避开视口边缘且不被详情面板遮挡。
- 备注编辑器支持标题、加粗、斜体、删除线、链接、列表、待办块、引用、分割线和图片。
- 详情面板内部滚动条使用窄型弱化样式，默认不抢视觉焦点，悬停时才提高可见度。

## 设置
- 设置从左上角进入，以右侧抽屉展示。
- 外观：4 套主题配色（青绿/海蓝/紫罗兰/石墨）、信息密度（舒适/紧凑）、侧栏折叠和详情面板默认显示。
- 个人资料位于侧栏顶部的“个人空间”，不属于设置抽屉：支持昵称、头像预览、更换头像和恢复默认头像；昵称错误在输入框下方即时说明，不使用模态报错。
- 任务显示：已完成任务在列表和分组中的显示、归位与默认展开规则。
- 应用行为与通知反馈：启动视图、启动提示、窗口关闭方式、系统提醒通知、提醒声音、操作音效总开关和分类开关（任务/清单/分组）。垃圾桶保留期、附件清理和恢复点归个人空间的数据入口，不在设置页重复展示。
- 关于与更新：应用图标、名称、版本、平台信息和更新状态；未提供签名更新清单时明确引导到 Release 手动安装。
- 设置变更即时生效并通过本地数据持久化。
- 详情面板支持拖拽调整宽度（320-800px），宽度持久化到设置。

## 操作音效
- 基于 Web Audio API 合成，无外部音频文件；音效短促、低音量，并按总开关和任务/清单/分组/拖拽分类开关控制。
- 完成使用明亮上行确认；新增、恢复和标记使用可区分的轻提示；撤销使用柔和回弹；移入垃圾桶和永久清理使用圆润下行，避免刺耳或在笔记本扬声器上不可闻。
- 拖拽只在开始、经过目标和结束时提供极轻反馈，不能用高频声音替代视觉状态。
- 保存失败的反馈以可见错误为主，音效不能成为唯一告警方式。
- 支持总开关和分类独立开关（任务/清单/分组），设置持久化到 SQLite。

## 可访问性
- 图标按钮必须提供 `aria-label` 或可见文字。
- 焦点环不能移除。
- 颜色不能作为唯一状态提示，重要状态配合图标或文字。
- 桌面紧凑界面的图标操作保持足够点击面积；高频或危险操作不得只依赖悬停，也必须提供键盘或明确菜单入口。
- 动画遵守 `prefers-reduced-motion`。
