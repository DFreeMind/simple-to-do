# 易简清单 0.5.2

## 主要更新

- 任务详情支持选择“当前窗口内展开”或“自动扩展窗口”；设置中提供布局预览，切换时钟后的详情残留问题也已修复。
- 专注开始前的任务选择器与专注回顾筛选器升级为紧凑浮层，搜索、关联、计划与筛选操作更集中。
- 成长徽章完善收藏卡、详情和追踪信息；花种图鉴继续优化培养进度、解锁门槛、花语、回放轨道和陪伴等级展示。
- 修复 macOS 更新完成后可能停留在“正在重启”的问题，更新安装后的重启流程更可靠。

## 数据与兼容性

- 继续使用本地 SQLite 数据；升级不会要求账号或云同步。
- 既有任务、专注记录、花园和成长徽章数据保持兼容，无需迁移。
- 建议在“个人空间 → 数据与安全”创建本机恢复点后再安装更新。
